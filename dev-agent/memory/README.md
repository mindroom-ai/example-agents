# Daily Memory

Place daily notes here as `YYYY-MM-DD.md`.

Suggested structure:

```markdown
# 2026-04-18

## Threads
- ISSUE-042: current phase, latest SHA, next check

## Decisions
- what changed and why

## Follow-ups
- what should be picked up next session
```

These files are intentionally ignored by git so the workspace can accumulate local context without turning the public example into a diary.

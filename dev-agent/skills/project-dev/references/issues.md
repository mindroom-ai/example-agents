# Project Issue Tracker

## Format

- `[USER]` means human-reported
- `[AUTO]` means agent-detected
- phases: `P0` plan, `P1` implement, `P2` review, `P3` fix, `P4` live test, `P5` merge

## Open

### ISSUE-001 [USER]

- **Title:** Example bug or feature request
- **Status:** OPEN
- **Phase:** P0
- **Severity:** high
- **Summary:** Short problem statement
- **Report:** `references/reports/ISSUE-001.md`

### ISSUE-002 [AUTO]

- **Title:** Example agent-detected regression
- **Status:** IN PROGRESS
- **Phase:** P2
- **Severity:** medium
- **Summary:** Short problem statement
- **Report:** `references/reports/ISSUE-002.md`

## Approval Pending

### ISSUE-003 [USER]

- **Title:** Example issue waiting for human verification
- **Status:** APPROVAL PENDING
- **Phase:** P5
- **Severity:** medium
- **Summary:** Fix merged, waiting for operator confirmation
- **Report:** `references/reports/ISSUE-003.md`

## Closed

Move issues here once a human confirms the result.
